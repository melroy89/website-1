Vikunja is available as an electron-based desktop application for Linux and Windows.
For advanced desktop instructions, see [the desktop README](https://github.com/go-vikunja/vikunja/blob/main/desktop/README.md).

## Installation

1. Download the latest release for your platform from [the download page](https://dl.vikunja.io/desktop/).
  * For Windows, choose the file with the `.exe` or `.msi` file ending
  * For a Linux-based operating system, choose a file with an ending for your operating system - we have builds for Alpine, AppImage, Arch Linux, Debian-based systems, FreeBSD, Fedora and Snap.
2. Run the downloaded package in the same way you would normally install a package for your OS.

**Note:** If you're self-hosting your Vikunja instance, you need to [enable cors](/docs/config-options#0--cors) for at least the host `http://127.0.0.1:45735` for the desktop application to work.

## Flatpak

Vikunja Desktop can be installed via the [Flathub](https://flathub.org/apps/io.vikunja.Vikunja).

To install it, run the following command:

```sh
flatpak install flathub io.vikunja.Vikunja
```

## Logging in

<Callout type="info">
The OAuth-based desktop login is available from Vikunja **2.3.0** onwards.
</Callout>

The first time you open the desktop app, you'll be asked to pick which server to connect to:

- **Vikunja Cloud:** connect to the hosted [Vikunja Cloud](https://vikunja.cloud) service.
- **Try Demo:** connect to `try.vikunja.io`, the public demo instance.
- **Custom Server:** enter the URL of your own self-hosted Vikunja instance.

After you pick a server, the desktop app opens your system browser and walks you through an OAuth 2.0 sign-in flow. This is the same flow a browser login uses, so if your instance is configured with an external identity provider (for example via OIDC), you can sign in through it here as well. Once you approve the sign-in, the browser hands control back to the desktop app automatically and you land in Vikunja.

This is built on Vikunja's [OAuth 2.0 authorization server](/docs/oauth-server), so the same mechanism can be used by other clients and integrations.

## Quick-entry window

<Callout type="info">
The quick-entry window is available from Vikunja **2.3.0** onwards.
</Callout>

The desktop app has a dedicated **quick-entry window**: a small popup you can open from anywhere on your system to add a task without first switching to the main Vikunja window.

### Opening the popup

Press the global shortcut to open the popup. The default is `Ctrl` + `Shift` + `A` (or `Cmd` + `Shift` + `A` on macOS).

You can change the shortcut in **Settings > General**, under the Desktop section. Click the shortcut recorder and press the key combination you want to use.

You can also open the popup from the [system tray](#system-tray) or by launching the app with the [`--quick-entry`](#command-line-flags) flag.

### Creating a task

The popup uses the same quick-entry interface as the [dashboard quick-add bar](/help/dashboard#quick-add-bar), so you can use [Quick Add Magic](/help/quick-add-magic) to set due dates, labels, priorities, assignees, and the target project while you type.

- **Enter** creates the task and closes the popup.
- **`Ctrl`** / **`Cmd`** + **Enter** creates the task and opens it in the main Vikunja window.
- **Esc** closes the popup without creating a task.

## System tray

The desktop app places an icon in your system tray with these entries:

- **Show Vikunja:** open or focus the main window.
- **Quick Add Task:** open the [quick-entry window](#quick-entry-window). The current global shortcut is shown next to the menu item.
- **Quit:** close the app entirely.

## Command-line flags

- `--quick-entry`: launch the app and immediately open the [quick-entry window](#quick-entry-window). If Vikunja is already running, this opens the popup in the existing instance instead of starting a second one. This is useful if you want to bind your own shortcut or launcher to the quick-entry window.
